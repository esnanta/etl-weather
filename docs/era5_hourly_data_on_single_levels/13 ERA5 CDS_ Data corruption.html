The following CDS catalogue entries (datasets) were affected: * ERA5 hourly data on single levels from 1979 to present * ERA5 hourly data on pressure levels from 1979 to present We have identified a few hundred corrupted fields, out of a total of 3.1 billion fields. The corruptions usually manifest themselves as a latitudinal line or band of spurious values. These data corruption problems were caused by a disk problem. These data corruptions did *NOT* affect the ERA5 data on MARS. We apologize for the inconvenience this may have caused. / / A data corruption example The following figure of the ERA5 2m temperature field for 1990-07-19 17 UTC (number 295 in the the table below), shows a typical example of the data corruption. The corruption shows up as a horizontal line of low values in the map. / / List of corrupted ERA5 fields The tables below provide the list of the ERA5 fields that we have found to have suffered a corruption out of a total of 3.1 billion ERA5 fields. The column titles in 'quotes' are CDS keywords that identify the ERA5 fields. Number is the ensemble member (ranging from 0-9) that is affected for 'ensemble_members'; it is blank for other product types. The number of grid points that were affected are also indicated in the table. Note that for 0.25-degree ERA5 fields (i.e. most 'reanalysis' fields), one latitude line contains 1,440 and a complete ERA5 field 1,038,240 grid points. For 0.5-degree ERA5 fields and 1.0-degree ERA5 fields this is about a factor 4 and 16 lower, respectively. The tables can be resorted according to particular columns by clicking on the corresponding column head. Users that have downloaded ERA5 fields from the CDS disks, in the list below, prior to the date when the files were corrected (indicated in the table), are *recommended to re-download* them. Note that, to date, files were fixed in *two separate batches* when the corruption was identified.
